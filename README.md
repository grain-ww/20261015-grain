# Grain

**Status:** Living -- the front door of the tree.

A small beginning, grown one line at a time.

Here we build one thing, then the next, and we read every line before it lands. The tree grows the
way a garden does: each bed is tended until it is green, and only then is the next one planted.

## The near aim

**Caravan** is a supervisor written in **Rye**, standing as a root task on **seL4**, the microkernel
whose correctness has been proved. We build it under the **GNU General Public License, version 3**, so
the freedom to read, run, study, and share this work travels with every copy of it.

## The name

A tree carries the date of its first commit, as its folders carry the date of their making. This tree
is `20261015-grain`. The name says when this beginning began, and it never moves. A later tree takes
a later date, and the two stand side by side, each whole.

## The order we build in

Simple, then Lovable, then Complete. A system that works grows from a simpler one that already works,
so each piece stays small enough to hold in one hand and one mind.

Safety comes first, and it is built into the shape of the code. Performance comes second, and it is
measured before it is changed. Joy comes third: the clarity of a named thing, and the habit of saying
why.

## Keys

Commits are signed with a key held in `.gnupg-rye/`. Git never tracks that folder, so the key never
enters history. The reasons, and how to check them, are in [`context/KEYS.md`](context/KEYS.md).
