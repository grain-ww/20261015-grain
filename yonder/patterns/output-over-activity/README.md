# Output over activity -- a general pattern

**Stamp:** `20261017.190500`
**Status:** Living pattern -- general, carries no project's numbers
**Room:** checkable for the measure shape; the discipline is vision.

## Outcome

A team can state, each round, what it produced as a whole and whether that output moved, with a
partner indicator beside every output measure, so no gain hides a loss.

## The shape

1. **Measure the whole.** Output belongs to everyone the work touched, not to the hour one person spent.
2. **Pair every measure.** Each output measure carries a partner that would move if the output were bought
   with a hidden loss. See [`MEASURES.md`](MEASURES.md).
3. **Baseline first.** Measure before any change. A row without a baseline is a plan.
4. **Count, do not admire.** Simplification is a counted step count with a target set before the examination.
5. **Date everything.** Dated files are testimony; a later reading is a new file.

## Instances

A project instantiates this pattern by copying [`MEASURES.md`](MEASURES.md), filling the baseline column,
and naming its own owner and dates. The clean-slate pier's instance is
[`projects/20261015-grain/output-over-activity/`](../../projects/20261015-grain/output-over-activity/README.md).
