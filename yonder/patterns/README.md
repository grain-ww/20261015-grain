# Patterns -- general shapes that any project may instantiate

**Stamp:** `20261017.190500`
**Status:** Living -- the room for general patterns. Nothing here names one pier, one project, or one person.
**Room:** checkable -- each pattern is a shape with measures a reader can check.

A **pattern** is a shape of work that holds on any pier: a way to measure output, a path to learn a
system, a way to ship. A **project** instantiates a pattern by naming its own outcome, baseline, and
dates. The pattern never carries a project's numbers.

## The patterns

- [`output-over-activity/`](output-over-activity/README.md) -- measure what the whole produced, with a partner for every output
- [`slc-path/`](slc-path/README.md) -- the ordered path a learner walks through one system
- [`send-and-publish/`](send-and-publish/README.md) -- the default way to ship: log, commit, push to private remotes; public only on a word
