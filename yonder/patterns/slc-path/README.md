# SLC path -- the ordered walk through one system

**Stamp:** `20261017.190500`
**Status:** Living pattern, draft -- general. Steps are generic; an instance names its own system.
**Room:** checkable -- each step names a measure a reader can read.

## The path

Each step names what the learner does, what they can see when it works, and the measure that shows it.

| Step | The learner does | They can see it work | Measure (see output-over-activity) |
|---|---|---|---|
| 0. Start here | reads one front page and nothing else | the page names the next step | first-page completion |
| 1. Concept | reads one short page on the idea | they can say the idea back | concept check, once per page |
| 2. First run | runs the smallest working example | a green line or a plain result | first-run success, partner: first-run errors |
| 3. Change one thing | edits the example and runs it again | the result moves as predicted | prediction hits, partner: unexplained changes |
| 4. Read the record | reads the log of what changed | every change has a stamp | records read, partner: records missing |
| 5. Ship | sends the change with the send pattern | the change lands on a remote | sends landed, partner: sends reverted |

## Simplify the path

Count the steps before and after each review. A target of a third fewer steps on the first pass is ordinary.
Remove a step only when no reader needs its answer.

## Link to measures

Each page on the path declares the measure row it serves. A page with no measure row is a page nobody checks.
