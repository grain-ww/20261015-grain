# Private -- the room for what stays out of git

**Status:** Template. Copy the rules below into your own notes; nothing in this folder is published.
**Tutorial:** [`docs-geode/tutorials/07-the-private-room.md`](../docs-geode/tutorials/07-the-private-room.md)

This folder is ignored by git on purpose. Anything you put here stays on this machine, and no commit, push, or public
snapshot will carry it.

## What belongs here

- Session logs that name private people, accounts, or held material.
- Drafts from a held document, such as a scripture review, a personal project page, or a vendor summary.
- Anything the public-export audit has marked as held.

## What does not belong here

- Code, witnesses, or any file a reader needs to build the tree. Those go in the tree.
- A copy you need to keep safe. Git does not back this folder up, so keep a second copy somewhere private.

## Backup

The second copy is the private repository `grain-ww/20261015-grain-private`. It holds the held tablecloth files and the generation PNGs, and it is private.
