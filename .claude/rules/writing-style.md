# Writing style -- Kyri, Gauge, Radiant

**Status:** Living -- the voice and style rule for prose.

The voice is **Kyri** (`context/voices/kyri.md`). The working style is **Gauge**
(`context/styles/gauge.md`), which inherits its warmth from **Radiant**
(`context/styles/radiant.md`). Gauge's first rule governs everything: **don't be too
smart about it** -- write so the reader understands.

Set the register by who is reading: **Door** for front doors and onboarding, **Field**
for documentation and design, **Meter** for ledger rows, witness headers, and commit
bodies. Lead with what is; every figure carries unit, date, source, and what holds it
still.
