# Reds first

**Status:** Living -- the red-first rule for work that goes wrong.

A **red** is something wrong. When one is found, write it down: what went wrong, what caught it,
and what it taught. Then book the rest of the round to reds before opening new work. A fix closes on a
**witness run in the same round**, rather than on a claim.

A **ratchet** is something not yet uniform. It turns on touch and stays out of the ledger. Cite a red as `REDS %7`, using the
percent sigil, rather than `#`.
