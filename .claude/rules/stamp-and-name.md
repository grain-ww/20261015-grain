# Stamp and name

**Status:** Living -- the mark rule: a stamp and a name, not a counted rung.

The ordering rules this page uses are stated once in [`context/order.md`](../../context/order.md).

A mark is a **stamp and a name**. The stamp orders it (from the one clock); the name says
what the work was. Mark by stamp and name rather than by an ascending number: a counted rung
forecasts a length the work may not keep. Count with `git log` rather than carrying a total
inside a name.

Keep the whole stamp in every filename: `date/YYYYMMDD/YYYYMMDD-HHMMSS_sprig.ext`. The move
from an old path to a folded one is then a pure function of the basename, so a stale reference
is resolved rather than rewritten. A room folds past 256 flat files.
