# Errata -- the tablecloth as a document room

**Kind:** errata. It corrects a description and leaves the dated records as written.
**Corrects:** the tablecloth audit note (`tablecloth/documents/notes/date/20261018/20261018-023528_tablecloth-audit.md`) and the
replay output (`tablecloth/documents/context-data/replay/commits.txt`), which describe the tablecloth as a personal folder.

## What is true now

`tablecloth/` is the document room. Its README describes it as a room for documents, filed the way a Finder window is, with
working notes and first-hand pages. Personal and held material is kept in `tablecloth/private/`, which is excluded from the public
snapshot. The earlier name, the personal Documents tree, is retired in living pages.

## What this does not change

The audit note and the replay output keep their words. The replay output is regenerated from the tree, so its wording follows the
README at its next run.
