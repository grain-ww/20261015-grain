## Running Glow, Rye, and Rishi

These three -- a language (Glow), its systems tongue (Rye), and its shell (Rishi) -- are
pre-alpha, and their toolchain is not vendored into this nearly-blank tree yet. Bootstrapping
it from the `20260618-grain` field is the **first build lap**, and it is deliberately held
until the prose above is settled, so the tree stays readable while it is still small. When
that lap lands, this section will carry the exact commands and what you will see turn green.

## The habit

At the end of each working session, a `.kyri` session log is written to `session-logs/`.
Every commit is signed. We keep plain ASCII. We read every line before it lands.
