# Single-stranded

A thing is **simple** when it is un-braided: one fact living in one place, read from many.
It is **complex** when two concerns are folded together, so that touching one tugs the other.
Simple is a property of the thing, not of how hard it was to make.

The date-prefix is the first strand we pull clean. Rather than writing `~/grain-incense` into
every script, we name the prefix once as a variable and prepend it. Changing the prefix then
changes one value rather than a thousand paths, and a reader who wants to know where the tree
lives has exactly one place to look. We reach for strict, single-stranded shapes early,
because untangling later costs far more than keeping clean now.
