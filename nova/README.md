# Nova -- the Grain navigation language

**Status:** Living. The design root for how a person moves through this tree.

Nova is the navigation language of this tree. It graduates from the spellbook: a spell is a short letter that names a path through the tree, and Nova is where those letters live, in one strand, with the rule for each.

## What lives here

- `spells.brix`: the strand. One fact per line: `spell NAME MEANING`, `alias`, `trigger`, `limit`. The spell check reads it.
- This page: what Nova is and how a spell is read.

## How a spell reads

A letter runs its meaning in order. `s` is `z study l r a t`, so the steps run inside the study folder. `bn` is `b` for Nova, run with Nova's own spells beside `s`, `l`, `r`, `o`, and `w`. A spell that publishes (`w`) still waits for its owner's word.

## What it supersedes

The spellbook in `context/SPELLBOOK.md` pointed at the strand. It now points here. Dated records that name the old path keep their words.
