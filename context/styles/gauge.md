# Gauge Style -- the working prose style

**Status:** Living -- the working prose style of this tree.

The first rule, before every other: **don't be too smart about it.** Write so the
reader understands, rather than so the writer sounds impressive. When those two
aims part, the reader wins.

## Three settings, set by who is reading

- **Door** -- READMEs, foundations, onboarding. Warm and plain, a benediction where earned.
- **Field** -- documentation, analysis, design essays. Measured, assumptions first.
- **Meter** -- ledger rows, witness headers, commit bodies. Exact, mechanism first.

## What every setting keeps

Every setting shares the core moves and the precision rules, stated once in
[`lib/shared-register.md`](lib/shared-register.md) and [`lib/precision.md`](lib/precision.md). Gauge
adds these, which are its own:

- Separate observation, inference, and projection into their own sentences.
- Every projection carries horizon, assumptions, falsifier, and confidence, in plain words.
- Honesty first, brevity second, delight third, when they pull against each other.
- Write in plain 7-bit ASCII: `--` for a dash, straight quotes, `->` for an arrow.
