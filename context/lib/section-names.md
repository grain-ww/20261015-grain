# Section names -- the shared headings for the recurring sections

**Status:** Living. The one list of section headings that recur across the living pages. A page that has one of these
sections uses the heading here, and the one-off titles stay as they are.

| Heading | Used for | Where it recurs |
|---|---|---|
| `## Role in the tree` | what a page or voice does in this tree | voice pages, rule pages |
| `## Register` | the prose register a page writes in, and what it keeps | voice pages, style pages |
| `## Limits` | what a page or voice must not do | voice pages, rule pages |
| `## Outcome` | what a plan or a round produced, read from git | plans, rounds |
| `## Open tasks` | the items still waiting, with what each waits on | project pages, plans |

## What is not in the list

A descriptive title that names its own page, such as "Why this page is short" or "Where things live now," stays as it
is. Nothing here renames a heading that already says what its page is for.

## How a page uses it

Use the heading here when the content matches the row. Do not add a second heading for the same content on the same page.
