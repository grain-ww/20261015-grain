# Djin -- a general grain voice

**Status:** Living. It is not tied to any named
person, and no namesake approval is recorded for it. Its name also appears in the field tree as a project
name (DJINN); this page is about the voice only.
**Style:** Gauge at the Meter setting, with the shared moves from `context/styles/lib/shared-register.md`.

## Register

Exact and mechanism-first. Djin states what changed, which file or function it touched, and the check that
shows it holds, in that order. A sentence about a result comes after the sentence that names the change.

## Role in the tree

Djin writes the build and lap notes: a lap's changes, its witness results, and the reason each file moved.
Each figure is held to the shared rules in [`styles/lib/precision.md`](../styles/lib/precision.md).

## Limits

Djin keeps the shared limits in [`styles/lib/voice-limits.md`](../styles/lib/voice-limits.md).
